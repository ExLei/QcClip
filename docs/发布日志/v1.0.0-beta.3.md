# 🎉 版本 v1.0.0-beta.3 更新日志

## QcClip 版本更新

### 新增

- **粘贴热度滚动条**：替换原有列表滚动条，通过颜色展示不同区域的粘贴热度，悬停可查看粘贴次数，方便定位常用内容。
- **鼠标左键纯文本粘贴**：左键行为新增“单击粘贴纯文本”和“双击粘贴纯文本”，可按使用习惯选择粘贴方式。
- **Tab 栏悬停切换**：在设置中开启后，鼠标停留在 Tab 栏按钮上即可切换页面、类型筛选或展开标签面板。
- **标签选择管理**：标签面板新增“重置所有选择”和“切换页面时清空选择”，支持一键取消全部标签选择，也可在切换到历史或收藏页面时自动清空标签选择。
- **全局通知位置与时长**：支持选择屏幕八个方向的通知显示位置，并自定义通知显示时长。
- **主窗口快捷清理历史**：“更多操作”菜单新增“清理剪贴板”入口，可选择保留置顶记录或清空全部历史。
- **启动时清理历史**：数据管理新增“启动时清空待清理历史”开关，开启后每次启动自动永久删除超出保留时间或条数上限的待清理历史，保留置顶记录与收藏。
- **图片预览大小记忆**：自动保存图片预览的缩放基准大小，切换图片或重启应用后继续沿用上次调整的大小。
- **图库 GIF 自动播放开关**：支持自动循环播放图库可见区域内的 GIF，关闭后仅在鼠标悬停时播放。
- **列表图片体积显示**：图片条目新增体积信息，便于直接在列表中查看图片大小。

---

### 优化

- **相同文本格式合并与入库性能**：复制相同文本时自动合并不同来源的剪贴板格式，减少重复记录并保留更多可用格式；同时优化去重查询与格式写入，降低大量历史记录下的入库耗时。
- **后台 CPU 占用**：减少窗口隐藏时的鼠标事件处理、通知更新与后台唤醒，降低应用在后台运行时的 CPU 占用。
- **列表交互性能**：降低列表悬停与滚动加载时的 CPU 开销，改善连续浏览大量记录时的流畅度。
- **预览信息与定位**：根据内容类型展示体积、分辨率、字符数、来源应用、最近复制时间和粘贴次数等更多信息，并优化预览及信息区域的定位逻辑。
- **批量操作反馈**：批量数据操作期间为主窗口添加遮罩与处理中提示，避免重复操作或误触。
- **Windows 10 窗口圆角**：使用自绘圆角改善 Windows 10 下的窗口外观，开启窗口材质时自动禁用圆角。

---

### 修复

- **旧版 Windows 10 启动**：修复部分较旧版本的 Windows 10 因图形接口兼容问题无法启动应用的问题。
- **划词工具临时内容过滤**：修复划词工具短暂写入剪贴板的内容未被正确过滤、意外进入历史记录的问题。
- **历史清理空间回收**：修复清理历史后数据库文件空间未回收的问题。
- **Shift 多选顺序**：修复按住 Shift 向上或向下连续选择时，条目顺序未按选择方向排列的问题。
- **悬停预览恢复**：修复预览期间鼠标移出窗口后，重新移入无法恢复预览显示的问题。
- **条目序号宽度**：修复序号容器未随数字位数增加而正确扩展、导致序号显示不完整的问题。
- **无间模式选中边框**：修复列表无间模式下，选中条目的左右边框不可见的问题。
