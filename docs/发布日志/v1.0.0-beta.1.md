# QcClip v1.0.0-beta.1：首个公开测试版

QcClip 首个公开测试版来了！

QcClip 重写自作者此前开发的 [QuickClipboard](https://github.com/mosheng1/QuickClipboard)，延续剪贴板历史、收藏和快捷粘贴的使用体验，采用纯 Rust 与 GPUI 原生渲染重新实现。这是 QcClip 的全新起点，首发版本为 **v1.0.0-beta.1**。

本次首发面向 **Windows**，提供 x64、ARM64 两种架构的安装版和便携版。macOS 与 Linux 支持仍在完善中。当前为 **Beta 测试版**，欢迎体验并反馈问题，重要数据建议定期导出备份。

## 原生界面与日常使用体验

- 使用 GPUI 原生渲染，界面不依赖 WebView 或浏览器内核。
- 历史列表采用虚拟列表和按需加载，减少大量记录同时渲染的开销。
- 图片、应用图标等预览按浏览范围加载，并清理不再需要的缓存。
- 相同剪贴板内容按完整格式集合去重，减少重复存储。

## 剪贴板历史与内容预览

- 自动记录文字、链接、图片、文件列表及 HTML、RTF 等富文本格式。
- 同一条内容保留多种剪贴板格式，可选择复制或粘贴的格式。
- 支持按内容、备注和来源应用名称搜索，按文字、图片、文件、链接，以及是否已粘贴筛选。
- 支持悬停预览，并可分别设置列表展示与悬停预览的格式优先级。
- 支持打开链接、通过默认程序打开内容，以及使用自定义搜索引擎搜索条目文本。

## 收藏、标签与文本编辑

- 支持收藏、置顶和拖拽排序，集中保存常用回复、链接和资料。
- 支持彩色标签，一条内容可绑定多个标签，筛选时可选择匹配任意标签或全部标签。
- 支持为内容添加备注，历史与收藏共享标签和备注；备注不会加入复制或粘贴的正文。
- 支持手动新增和编辑文本；编辑已捕获的内容后，可恢复原始内容。

## 快捷粘贴与窗口操作

- 默认使用 **`Ctrl + Shift + X`** 显示或隐藏主窗口，支持自定义全局快捷键和窗口操作快捷键。
- 提供独立的便捷粘贴窗口，支持方向键选择条目、切换历史与收藏，可调整显示条数、宽度，并记住上次的列表位置。
- 支持快捷粘贴 1～9，可配置修饰键与数字键或 F1～F9，并选择是否包含置顶项。
- 支持保留格式粘贴、纯文本粘贴，以及将图片按图片文件粘贴。
- 支持多选合并复制和粘贴，可合并多段文字、图文内容或多个文件。
- 支持贴边隐藏、窗口固定、鼠标附近呼出和记住窗口位置。
- 支持自定义左键单击、双击和中键操作，以及粘贴后的列表排序行为。

## 表情、符号与图库

- 内置表情和符号库，支持分类浏览、搜索和最近使用记录，选中即可粘贴。
- 提供分组图库，支持导入本地图片和拖入浏览器图片，保存常用图片与表情包。
- 图库支持 PNG、JPG、JPEG、GIF、WebP 格式。
- 支持按文件名搜索图片、重命名、移动分组，以及按名称、类型或时间排序。

## 外观、隐私与数据管理

- 支持浅色、深色与跟随系统外观，多套主题配色，以及背景图片、透明度、列表样式、行高和动画设置。
- 支持简体中文和英文界面、托盘运行、全局通知及可自定义的操作音效。
- 安装版支持开机自启；Windows 下可设置管理员启动。
- 支持暂停剪贴板监听，并按前台应用限制内容监听、全局快捷键或贴边显示。
- 无需登录账号，剪贴板历史与图库素材保存在本地。
- 支持设置历史保留天数与最大条数。超出范围的历史先隐藏并计入待清理，主动清理前可通过放宽限制重新显示；置顶历史不受保留限制影响。
- 支持数据统计、清理，以及导出和导入 `.qcclip-data` 备份；安装版可更改数据保存位置。
- 支持手动和定期检查新版本，并可配置代理；发现更新后打开 GitHub 发布页下载。

## 从 QuickClipboard 迁移

旧版用户可在 **“设置 → 数据管理 → 从旧版 QuickClipboard 迁移”** 中迁移数据，当前以 QuickClipboard 正式版 **v0.5.0** 的数据为适配依据。

- 支持自动检测本地安装版数据、手动选择旧版数据目录或便携版目录，也可读取旧版导出的 ZIP。
- 默认迁移收藏，可选择同时迁移剪贴板历史。
- 旧版分组转换为标签，收藏标题写入备注，同一内容可以保留多个标签。
- 支持迁移已保存的文字、HTML、RTF、文件列表和 PNG 图片缓存，以及历史中的来源应用信息、置顶与粘贴统计。
- 执行前提供迁移预览，并自动备份 QcClip 当前数据；迁移以合并方式进行，重复迁移同一记录不会重复累计统计。

**旧版图库、设置和同步信息暂不迁移。** 文件列表仅保留文件路径，不复制实际文件；HTML 中引用旧目录的本地图片不会自动改写路径。建议先退出旧版程序，再进行迁移，并查看预览中的注意事项。

更详细的支持范围见 [旧版数据迁移说明](../legacy-migration.md)。

## 下载与使用

前往 [GitHub Releases](https://github.com/mosheng1/QcClip/releases) 下载与设备架构匹配的版本：

| 版本 | 文件 | 使用方式 |
| --- | --- | --- |
| Windows x64 安装版 | `QcClip_1.0.0-beta.1_x64-setup.exe` | 适用于常见的 Intel / AMD 64 位设备 |
| Windows x64 便携版 | `QcClip_1.0.0-beta.1_x64-portable.zip` | 解压后运行 `QcClip/QcClip.exe` |
| Windows ARM64 安装版 | `QcClip_1.0.0-beta.1_arm64-setup.exe` | 适用于 Windows ARM64 设备 |
| Windows ARM64 便携版 | `QcClip_1.0.0-beta.1_arm64-portable.zip` | 解压后运行 `QcClip/QcClip.exe` |

便携版数据保存在程序同目录的 **`QcClipData`** 中，移动时请退出程序并携带整个文件夹，升级时保留该数据目录及 `QcClip.portable` 标记。便携版不支持更改数据位置和开机自启。

## 当前使用边界

- 本次为 Beta 测试版，首发面向 Windows，macOS 与 Linux 暂不作为支持平台。
- 当前版本未提供云同步功能。
- 多选合并时，文件不能与文本混合合并，虚拟文件暂不支持合并。
- 富文本排版和图文合并的最终效果取决于目标应用支持的剪贴板格式。
- QcClip 数据备份导入会替换现有数据库，使用前请先导出当前数据；它与旧版数据的合并迁移不同。
- 更新检查仅提供版本提示与发布页入口，不自动下载或安装。

使用中遇到问题或有改进建议，欢迎在 [GitHub Issues](https://github.com/mosheng1/QcClip/issues) 反馈。感谢 QuickClipboard 用户一直以来的反馈与支持。
