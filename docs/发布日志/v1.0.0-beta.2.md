# 🎉 版本 v1.0.0-beta.2 更新日志

## QcClip 版本更新

### 新增

- **Tab 栏布局自定义**：支持拖拽调整页面、筛选和标签区域的排列顺序，以及各组按钮的顺序，并可按需显示或隐藏按钮。
- **条目信息与操作自定义**：支持分别设置首行信息、来源图标与序号、操作按钮的显示方式，可选择始终显示、悬停或选中时显示、隐藏，并逐项选择显示内容。提供默认、纯净、精简和完整四种预设。
- **鼠标中键呼出**：支持长按鼠标中键显示或隐藏剪贴板窗口，可搭配修饰键使用，并自定义长按触发时间。
- **全局界面缩放**：支持统一调整界面文字、图标和控件大小，修改后立即生效。
- **应用字体**：支持选择系统已安装的字体作为应用界面字体，也可跟随主题默认字体，修改后立即生效。
- **暮蓝主题**：新增暮蓝浅色与深色主题，提供更多外观选择。
- **标签面板宽度调整**：侧边模式下支持拖拽标签面板右侧边缘调整宽度。
- **标题栏右键菜单**：支持右键点击标题栏空白处打开“更多操作”菜单。
- **通知偏好管理**：支持分别开关启动提示、复制内容预览、功能状态、操作结果、警告与错误，以及发现新版本提醒，按需保留所需通知。
- **音效总开关**：支持一键开启或关闭全部操作音效，保留各项音效与音量设置。
- **关闭自动检查更新**：更新检查频率新增“永不更新”选项，关闭自动检查后仍可手动检查新版本。

---

### 优化

- **旧版数据迁移**：支持在分析前选择迁移收藏或历史，仅处理所选范围。取消十万条记录和原始数据累计 512 MiB 的迁移上限，改用磁盘暂存以降低内存占用；
- **单实例启动**：重复启动应用时唤起已有窗口，避免同时运行多个实例。
- **主题配色与文字对比度**：更新默认深色主题配色，柔化各主题颜色搭配，并改善文字对比度与内容辨识度。
- **字体显示适配**：列表行高根据所选字体调整，改善不同字体下的文字显示效果。
- **标签面板自动隐藏**：优化自动隐藏条件，避免在搜索输入、拖拽和面板内操作时意外收起。
- **下拉菜单选中项定位**：打开下拉菜单时自动滚动到当前选中项，减少查找与滚动操作。
- **临时快捷键范围批量设置**：支持一键全选或取消全部临时快捷键的“仅在窗口内生效”选项，减少逐项设置。

---

### 修复

- **搜索框自动聚焦**：修复呼出窗口后，搜索框自动聚焦失效的问题。
- **删除后列表刷新**：修复使用删除快捷键后，剪贴板列表未立即更新的问题。
- **标签搜索清空**：修复搜索标签后点击清空按钮，未恢复显示全部标签的问题。
- **标签面板鼠标交互**：修复鼠标在标签面板内移动时，误选下方剪贴板列表条目的问题。
