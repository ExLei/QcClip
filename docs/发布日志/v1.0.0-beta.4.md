# 🎉 版本 v1.0.0-beta.4 更新日志

## QcClip 版本更新

### 新增

- **自动下载与安装更新**：Windows 安装版和便携版均支持后台下载更新，并在关于页查看进度、取消或重试下载。自动下载默认开启，可按需关闭；下载完成后，点击“安装并重启”即可查看安装进度，完成后自动重启应用。
- **Gitee 更新回退**：优先通过 GitHub 检查和下载更新，失败或超时后自动尝试 Gitee；下载回退时匹配同一版本的更新包，改善 GitHub 访问受限时的更新体验。
- **窗口布局自动切换**：根据窗口显示位置自动切换列表布局，选择屏幕上、下边缘时使用横向布局，其他位置使用竖向布局，方便适配不同的屏幕空间与使用习惯。
- **剪贴板读取格式自定义**：默认仅读取常用剪贴板格式，减少部分应用生成特殊格式时引起的卡顿；支持自定义读取格式名单，也可开启“读取全部格式”以满足更多格式的保留需求。
- **内容预览类型自定义**：支持分别开启或关闭文本、HTML、图片和文件的悬停预览，按需选择允许展示的内容类型。
- **预览信息展示自定义**：支持逐项选择预览窗旁的信息与操作提示，包括体积、分辨率、字符数、来源应用和粘贴次数等，也可一键全部开启或关闭，关闭全部选项后隐藏信息条。
- **页面栏与筛选栏独立悬停切换**：支持分别开启页面栏、筛选栏的悬停切换，并独立设置鼠标停留时间，减少快速划过按钮时的误切换。
- **标签单选与多选切换**：标签面板新增单选／多选切换按钮，可直接在面板内切换选择方式。
- **粘贴热度滚动条开关**：支持按需关闭粘贴热度滚动条，关闭后使用原生滚动条。

---

### 优化

- **窗口材质与透明度**：优化启用窗口材质时的背景分层与透明度协调，改善各界面区域的层次感与显示效果。
- **背景图跟随窗口**：背景图改为随窗口移动，保持图片与窗口内容的相对位置，改善拖动窗口时的视觉连贯性。
- **预览视觉效果**：调整预览内容与信息条的背景、阴影和间距，提升内容辨识度与层次感。
- **深色模式热度配色**：优化深色模式下粘贴热度滚动条的配色，减少视觉突兀感。

---

### 修复

- **切换筛选时崩溃**：修复切换筛选条件时，虚拟列表缓存失效导致应用崩溃的问题。
- **企业微信图片粘贴**：修复向企业微信粘贴并发送图片后，图片被显示为文件的问题。
- **纯文本粘贴回退**：修复内容不含纯文本格式时无法正常执行纯文本粘贴的问题，现会自动回退为普通粘贴。
- **亚克力材质闪烁**：修复新建窗口时重复设置全局材质，导致已显示窗口的亚克力效果闪烁的问题。
- **自动回到顶部**：修复呼出窗口时能看到列表回顶滚动过程的问题，并修复自动回顶后未选中第一项的问题。
- **预览首帧闪烁**：修复切换预览内容时，首帧短暂闪现上一次预览内容的问题。
- **背景图加载**：修复部分背景图片无法正常加载的问题。
