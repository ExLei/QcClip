# 旧版 QuickClipboard 数据迁移

## 支持范围

迁移入口位于“设置 → 数据管理 → 从旧版 QuickClipboard 迁移”。
先选择是否迁移收藏和历史，再自动检测本地安装版数据、手动选择数据目录或便携版目录、选择旧版导出的 ZIP。
仅分析所选范围，更改范围会重新分析；未选择的记录和分组不参与转换。
适配依据为旧版正式发布版本 `v0.5.0`；更早版本允许缺少可选字段，实际支持程度以预览结果为准。

支持迁移：

- 收藏，默认勾选；分组转换为内容标签，收藏标题追加到内容备注。
- 剪贴板历史，可选；保留来源应用名称和缓存图标、历史置顶、相对排序和已有粘贴次数。
- 已保存的文本、HTML、RTF、文件列表原始格式。
- 旧版 PNG 图片缓存；读取图片字节并存入新版，不直接保留旧缓存路径。

不迁移图库、设置、同步身份、同步凭据、删除标记及窗口状态。
HTML 中引用旧目录的本地图片会列出注意事项，当前不会改写原始 HTML 字节。
文件列表仅保留路径，不复制用户实际文件；失效路径会在预览中列出。

## 分类与合并规则

旧版内置“全部”不转换为标签；空分组仍转换为标签。
标签名称去除首尾空格并转为小写匹配，同名标签保留新版已有颜色。
无效或超过 100 个字符的分组名称不会创建标签，所属收藏仍可迁移。
分组图标不迁移，分组颜色转换为 `#RRGGBB`。

内容按新版完整格式集合的哈希去重。显示文本相同但格式或字节不同的内容不合并。
同一份内容在不同分组出现时，保留一条收藏并绑定多个标签，不同标题汇总到备注。
标题写入备注时不添加迁移前缀，多个标题或已有备注之间使用空行分隔。
标签和备注属于内容，因此历史与收藏共享这些属性。
仅存在于旧收藏中的内容不会额外生成历史记录。

已有内容保留其内容字节、预览、当前位置、置顶和备注；旧标题只追加到备注。
历史时间范围及粘贴统计按旧记录补充；未知捕获次数不根据导入次数推断。
重复导入同一旧记录不会再次累计统计，也不会覆盖用户迁移后的修改。
用户删除已迁移内容或空分组标签后，重新迁移同一旧记录不会自动恢复它。

来源应用图标通过历史中的 `source_icon_hash` 读取旧版 `app_icons/<hash>.png`，
校验 PNG 和哈希后转换为新版 `application_icon_assets`，相同图标共用一个资产。
旧版没有保存可执行文件路径，因此不会根据应用名称构造新版路径缓存。
旧缓存缺失、损坏或路径越界时列出注意事项，仍保留历史及应用名称。
已迁移但缺图标的用户可重新选择同一旧目录或 ZIP，勾选历史并执行迁移以补全图标。
补全仅针对来源名称一致且图标为空的现存历史，不增加粘贴次数、不覆盖已有图标，也不恢复已删除历史。

## 执行与恢复

建议先退出旧版程序，再分析和迁移。
数据库使用 SQLite 在线备份生成快照，包含未做检查点的 WAL 内容。
分析期间不调用旧版初始化或升级逻辑，不修改旧数据库结构和版本。
记录按所选范围逐条读取，转换后的原始格式和应用图标存入临时 SQLite 数据库。
确认后逐条加载暂存内容，不依赖旧图片继续存在，也不把全部记录的原始字节保留在内存中。
取消预览、更换来源或关闭设置后，临时数据会随预览释放；暂存和数据库快照需要额外磁盘空间。

确认迁移后暂停新版数据操作，自动导出当前数据，然后用一个数据库事务合并记录。
备份位于当前数据目录旁的 `<数据目录名>-migration-backups`，文件后缀为 `.qcclip-data`。
失败时数据库事务回滚，并清理本次新增的正式二进制文件和应用图标文件。
备份可以通过原有“导入数据”入口恢复，该入口会替换数据，与合并迁移入口用途不同。

`legacy_import_records` 保存源记录指纹、对应内容 ID 及导入时间，随新版数据备份一起保存。
源指纹使用记录种类、旧 ID、创建时间及内容哈希，不依赖源目录或 ZIP 文件名。
这张表包含在 QcClip 的初始数据库结构中。

迁移不再限制记录总条数，也不再使用原始字节累计 512 MiB 的上限。
单个原始格式仍限制为 64 MiB（包含重建的格式），单条记录的旧版原始格式最多 256 个；超限记录会跳过并在预览中提示，其余记录继续迁移。
缓存图片超过 64 MiB 时跳过图片并提示，仍尝试迁移其他格式。来源图标最多 1 MiB、宽高各不超过 256 像素，超限仅跳过图标。
ZIP 最多一百万个条目，所需文件的解压总量最多 16 GiB；只解压数据库及 WAL、剪贴板图片缓存，以及勾选历史时的应用图标。
图库、设置等无关文件不解压，也不计入解压总量；所有条目仍校验路径穿越、绝对路径、符号链接和重复路径。
预览最多展示 100 项注意事项，总数仍会显示。

## 启动提示

本地检测读取 `%LOCALAPPDATA%\quickclipboard\settings.json`，优先使用有效的自定义存储目录，
否则查找默认目录中的 `quickclipboard.db`。任意位置的便携版需要手动选择。

检测到数据后显示“查看迁移、暂不迁移、不再提示”。查看迁移或选择不再提示后保存状态；
暂不迁移会在下次启动继续检测。手动入口始终可用。

## 验证

专项测试：`cargo test legacy_migration`。
覆盖内容去重、多标签、标题备注、时间单位、重复迁移、图片缓存、ZIP 输入、
路径穿越、源版本不变、事务回滚、二进制清理及备份恢复，以及图标迁移、重复迁移补全和图标清理。
另覆盖范围过滤、单条超限跳过、十万条以上读取、512 MiB 以上磁盘暂存、暂存损坏回滚和 ZIP 无关文件过滤。
